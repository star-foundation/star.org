# 公开登记表（给所有访客）

这个目录里存放着 Star.org 的**全部登记记录**，一条记录一个文件。
任何人——不需要注册、不需要登录、不需要付费——都可以查阅。

## 怎么核实一颗星有没有被重复登记

1. **拿到恒星编号**：证书或永久链接页面上写着一个编号，形如 `HIP-91262`。
2. **在本目录里搜这个编号**：在 GitHub 的搜索框输入 `HIP-91262`，或者在
   [公开登记表页面](https://star.org/registry/) 的搜索框里输入。
3. **看结果条数**：
   - 只搜到 **1 条** → 这颗恒星只被登记过一次，核实成功。
   - 搜到 **2 条及以上** → 说明出现了重复分配，属于我们的失误，请来信告知，我们会无条件退款或重新处理。

## 每条记录里有什么

```json
{
  "slug": "a1b2c3d4e5",              // 登记编号，等于永久链接 /s/a1b2c3d4e5/
  "star_id": "HIP-91262",            // 恒星编号，唯一对应一颗恒星
  "owner_display_name": "For Anna",  // 展示用称呼；选择匿名时这里是 null
  "anonymous": false,
  "dedication_message": "……",         // 献词，可以为空
  "registered_at": "2026-09-20T10:00:00.000Z",
  "star": { "ra": 279.23, "dec": 38.78, "magnitude": 0.03, "distance_ly": 25, ... }
}
```

**这里没有邮箱、没有订单号、没有任何支付信息**，也不会有真实姓名（如果登记人选择了匿名展示）。
索引文件 `../registry-index.json` 汇总了所有记录，程序化查重可以直接读它。

## 为什么这么做

同类纪念服务最常见的问题是"无法验证"：用户不知道自己的名字会不会被重复卖给别人。
把登记表完全公开，是这个问题唯一诚实的解法。记录一旦写入就不会被删除，
即使服务停止运营，这些文件仍然留在这里可以被查阅。
